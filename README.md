# ⚽ Calculadora de Traves

Uma ferramenta simples e prática para calcular a melhor forma de apostar no mercado **"Total de Chutes na Trave"**, com base nas odds da Superbet.

---

## 🧠 Criado por: **IcaroH**

---

## 🚀 Funcionalidades

- Cálculo automático da melhor divisão de valor entre odds
- Exibição do retorno total e lucro da aposta
- Repetição automática para novas simulações
- Validação de entrada para evitar erros
- Interface colorida no terminal (usando `colorama`)
- Executável `.exe` incluso para rodar sem precisar de Python

---

## 🖼️ Exemplo de uso

```bash
